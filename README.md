# Sistema de Cursos en Línea

## Descripción del Proyecto

Este es un sistema de gestión de cursos en línea desarrollado en C#. Permite administrar estudiantes, instructores, cursos e inscripciones de manera sencilla a través de una interfaz de consola. El sistema resuelve el problema de organizar y gestionar la información de cursos educativos, facilitando la inscripción de estudiantes y el seguimiento de sus progresos.

### Problema que Resuelve
- Gestión de usuarios: Centraliza la información de estudiantes e instructores.
- Administración de cursos: Permite crear cursos con instructores asignados y gestionar listas de estudiantes inscritos.
- Inscripciones: Registra las inscripciones con fechas y relaciona estudiantes con cursos específicos.
- Persistencia de datos: Utiliza archivos CSV para almacenar datos de estudiantes de forma persistente.
